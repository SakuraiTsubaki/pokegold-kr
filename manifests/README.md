# Manifests

Manifests provide machine-readable identity, provenance, generation, and verification metadata for Korean project artifacts.

Useful fields include stable artifact ID; target release/revision; source bank/section/address/symbol/index; text/font identifiers when relevant; source/output hashes; tool and command; format metadata; deduplication relationships; and verification evidence.

Do not invent unknown values. See `example.asset-manifest.json` for a minimal example.
