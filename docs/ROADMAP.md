# Roadmap

## Phase 1 — Korean baseline inventory
Identify exact Korean releases/revisions and hashes.

## Phase 2 — Architecture mapping
Map ROM layout, banks/sections, code regions, text/font systems, data structures, and pointers.

## Phase 3 — Source reconstruction
Reconstruct code, data, scripts, and Korean text into readable and editable source.

## Phase 4 — Assets and systems
Document and reconstruct graphics, audio, maps, UI, events, fonts, and other systems with provenance.

## Phase 5 — Build and verification
Add reproducible tooling, regression checks, and exact or criterion-based matching where appropriate.

## Phase 6 — Coverage expansion
Expand verified reconstruction without flattening meaningful Korean release/revision differences.
