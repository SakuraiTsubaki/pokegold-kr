# GOLD KR 전국도감 #001–#1025 엔진 확장 — Stage 0

## 기준 ROM
- `Pocket Monsters Geum (Korea).gbc`
- SHA-1: `c0ff3999e1093e1af59ef3eea3f1bfd7c1f18a65`
- 크기: 2 MiB, 매퍼/RTC 구조 유지

## 이번 단계에서 실제 적용한 것
- 원본 #001–#251 종 ID/데이터는 그대로 유지.
- `0xFC`를 확장종(EXMON) 표식으로 예약하고 `0xFD` EGG는 보존.
- Gold BoxMon의 미사용 2바이트(오프셋 29/30)를 16비트 전국도감 번호 저장 위치로 확정.
- #252–#1025 총 774종 인덱스를 ROM 뱅크 `0x6A`에 기록.
- 완전히 비어 있던 뱅크에 확장 데이터 영역을 예약.
- #252–#763은 `0x73`, #764–#1025는 `0x74`에 32바이트 원본형 base-data 레코드로 배치하도록 고정.
- ROM 글로벌 체크섬 재계산.

## 확장 파라미터 스키마 (원본 Gen II 엔진 우선)
### Base data 32 bytes
전국번호(확장종은 외부 16비트 ID가 진실원본), HP/공격/방어/스피드/특공/특방, 타입1/2, 포획률, 기본 경험치(1바이트 호환값), 지닌도구 1/2, 성비, 부화 사이클, 그래픽 크기, 성장률, 알그룹, TM/HM 호환 비트필드.

### 별도 확장 테이블
- 한국어 이름 / 도감 분류 / 신장 / 체중 / 설명
- 진화 조건과 진화 대상(16비트 종 ID)
- 레벨업 기술 / TM·HM 호환
- 스프라이트·팔레트·울음소리 far pointer
- 도감 seen/caught 확장 비트셋
- 현대 세대 전용 메타데이터(특성 등)는 원본 Gen II 전투 규칙과 분리 저장

## 예약 뱅크
- `0x6A`: 확장 디렉터리 + 엔진 메타데이터
- `0x73`: #252–#763 base data (512 × 32 = 16 KiB)
- `0x74`: #764–#1025 base data + 잔여 공간
- `0x75`: 이름/문자열 포인터
- `0x76`: 진화 데이터
- `0x77`: 레벨업/TM 데이터
- `0x7C–0x7D`: 도감 메타/설명
- `0x7E`: 그래픽 인덱스

## 런타임에서 다음으로 연결할 핵심 함수
1. `GetTrueSpeciesID`: legacy byte 또는 `0xFC + ext16`을 16비트 ID로 정규화
2. `GetBaseData`: #001–251은 원본 테이블, #252–1025는 0x73/0x74 산술 로더
3. 이름/도감/스프라이트/울음소리 로더의 far-pointer 분기
4. 진화/기술 학습/야생/트레이너/파티/박스의 종 비교를 확장 ID 안전 방식으로 변경
5. 도감 seen/caught를 1025종으로 확장

## 중요
이 Stage 0 ROM은 **저장공간·식별 체계만 실제로 삽입한 기반 ROM**이다. #252–#1025의 실제 게임 파라미터와 런타임 훅은 아직 넣지 않았으므로, 현재 시점에서 1025종이 플레이 가능하다고 표시하지 않는다.

> NOTE: 이 Stage 0 sentinel 설계는 역사적 프로토타입이다. 현재 최종 아키텍처는 `../GOLD_ROM_LIMITS_AND_ARCHITECTURE.md`의 native 16-bit Species/Variety/Form 설계를 따른다.
