# GOLD GitHub 반영 정책

이 저장소의 GOLD 한국어판 작업은 다음 원칙으로 반영한다.

## 자동 반영 대상

작업 과정에서 생성되는 안전한 산출물은 작업 단위가 끝날 때 저장소에 반영한다.

- 소스 코드
- 빌드/추출/검증 스크립트
- 패치 파일(IPS/BPS 등)
- 매니페스트 / 해시 / 검증 결과
- 구조 분석 / 주소표 / 기술 문서
- 데이터 원장 및 변환 규칙

## 업로드 금지

저작권 원본 바이너리는 저장소에 올리지 않는다.

- 원본 `.gbc/.gb/.gba` ROM
- 원본 ROM을 사실상 그대로 복원할 수 있는 무가공 덤프

수정 ROM도 기본적으로 저장소에 직접 넣지 않고, 재현 가능한 소스/패치/빌드 지침으로 관리한다.
